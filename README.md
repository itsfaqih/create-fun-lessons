# create-fun-lessons

An agent skill that turns a codebase, library, or topic into a playful course on one HTML page: a lesson map of short units; quizzes, typed commands, and written code or essay exercises with instant feedback; retries of missed questions, XP, a daily streak, and saved progress.

The skill lives in [`skills/create-fun-lessons/`](skills/create-fun-lessons/SKILL.md). Install it by linking or copying that folder into your agent's skills directory, for example `~/.claude/skills/create-fun-lessons`.

Created in [T3 Code](https://t3.codes).
